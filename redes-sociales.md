## 6. Paso a paso para crear las cuentas

**Instagram**
1. Descargar Instagram → *Crear cuenta nueva* → usar un correo propio del negocio.
2. Elegir el usuario (sección 1) y subir la foto de perfil.
3. *Configuración → Tipo de cuenta → Cambiar a cuenta profesional → Empresa → Servicio de ingeniería*.
4. *Editar perfil*: pegar la biografía, el enlace de WhatsApp y activar los botones de contacto.
5. Publicar las 3 primeras piezas el mismo día, luego 3 por semana.

**Facebook**
1. Desde el Facebook personal: *Menú → Páginas → Crear página nueva*.
2. Nombre, categoría y biografía (sección 3).
3. Subir foto de perfil y portada.
4. *Agregar botón → Enviar mensaje de WhatsApp* → número +58 414 693 7820.
5. *Configuración → Cuentas vinculadas → Instagram* para publicar en ambas a la vez.

**WhatsApp Business**
1. Instalar WhatsApp Business y registrar el número (puede migrar el chat de WhatsApp normal).
2. *Herramientas para la empresa → Perfil*: completar los datos de la sección 4.
3. Configurar bienvenida, ausencia, respuestas rápidas y catálogo.
4. *Herramientas → Facebook e Instagram*: vincular las cuentas.
